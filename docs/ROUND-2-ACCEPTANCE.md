## 最后一次桌面贯通路径

使用独立验收副本，数据标识为 `dev.zhapar.seeker.round2`，未替换用户常用安装。
模型使用本机确定性 HTTP 夹具与 Ollama 协议，不读取或转发云端密钥。

1. 通过系统文件选择器导入 145 字节、51 字符的中文阅读安排 TXT，解析成功。
2. 从文件阅读页创建导图，经真实 Rust 生成通道收到 6 个节点。请求只有 system/user 两条消息，
   包含这次选中的正文，没有工具列表。
3. 将根节点改为“周末轻松阅读”，另一节点改为“周六上午专注阅读”，其余节点保留。
4. 从个人样式菜单应用“纸上阅读”，保存为 v2；原始导出预览显示 2966×554。
5. 切换到横向比例时 Mac 锁屏。带标题/来源/署名的 16:9 桌面 PNG/PDF、这条路径的最终重启检查，
   以及桌面聊天生成 Widget 后保存离线文件，待解锁后继续。前述浏览器或早期桌面检查不代替这一步。
