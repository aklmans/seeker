## 第二增量证据

- 新平台“我的作品”提供持久化、重命名、复制、可恢复移除和最近 20 个版本。源内容、样式、来源与空间字段分开保存。
- SQLite 迁移 16 / IndexedDB 版本 11、Runtime 契约、完整便携备份、精简导出排除和 AI 静态硬底已同步。
- 写入比较版本并使用原子事务；并发编辑只有一方成功，事务回滚保留原记录。保存时锁定表单，失败保留输入。知识卡片和六种独立风格提前接入底座，便于无模型验收。
- Widget 自动保存后，聊天消息持有作品引用，重启可以从历史重开。新回归先发现历史入口漏 import，再确认修复；源码与用户文本不进入父应用 HTML。
- 当前交互状态通过受控端口生成快照，单独 nonce iframe 进行本地绘制；不开放同源权限、不改 live 组件。保存 PNG / 长页栅格 PDF 与复制图片使用同一预览。
- 前端 151 项单测及 typecheck 通过；全量 Chromium 42 项通过，作品相关 WebKit 5 项通过。回归覆盖版本、失败保留、复制与撤销、风格独立、备份往返、Widget 历史、长中文与当前输入导出、恶意快照脚本/外链拒绝。
- Rust 242 项单测通过、4 项忽略，parser CLI 1 项通过；fmt、Clippy 通过。新增校验覆盖损坏记录、版本冲突、图片解码、栅格 PDF 与实际文件校验。
- agent-browser 实际操作知识卡片与风格并检查预览。WebKit 的懒加载未就绪和浏览器的零尺寸布局误报先复现再修复；选中作品立即加载，截图等待布局完成，独立画布保持在视口内的透明层。
- 独立桌面副本实际创建“桌面阅读卡”、使用杂志风格、保存中文分行正文，退出再启动后原文和样式恢复。真实 UI 导出 PNG / PDF，`pdfinfo` 确认单页、无脚本，PDF 实际渲染尺寸与 PNG 一致。
- 桌面剪贴板写入后，从系统读回 TIFF，与 748×576 的 PNG 逐像素比较一致。测试图片、PDF 和临时验收副本不入库。

本批手动功能未调用模型；Widget 聊天链用确定性事件验证，真实模型生成质量、Windows 真机未覆盖。
当前 PDF 为图片页；自由 Widget 重新打开时重新运行源码，交互状态只在静态导出时捕获。
个人样式收藏/默认值、思维导图、其余作品类型、比例/署名与离线交互分享继续按原范围实施，不代表整轮已完成。
