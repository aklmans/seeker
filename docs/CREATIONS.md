# 我的作品

第二轮已提供 Widget 保存与历史重开、知识卡片、可编辑思维导图、对比表、时间线、个人样式、版本恢复、
PNG / 长页 PDF、复制图片、分享比例与附加文字，以及 Widget 离线交互文件。

## 保存与编辑

- 聊天生成的 Widget 自动进入“我的作品”。卡片显示实际保存结果，失败可以重试；聊天历史提供重新打开入口。
- 从“我的作品”新建知识卡片，填写标题和正文，选择风格后点“保存修改”。这些操作不需要模型。
- 六种独立风格可以继续调整背景、文字、强调色、卡片底色、字体、字号、间距和圆角。Widget 另外提供“跟随应用主题”，切换深浅色不重置当前交互。
- 自由 Widget 的结构由 HTML 决定。高级入口可编辑源码，重新打开会重新运行交互；写死的局部样式可能不会完全跟随风格控件。
- 复制会生成独立作品。移除后可用“撤销”恢复，也可勾选“已移除”再恢复。修改记录保留最近 20 个版本；恢复旧版会生成一个新版本。
- 保存期间表单暂时锁定。保存失败保留当前输入；若作品已在另一页面更新，需要重新打开再修改，不会覆盖较新的内容。

## 我的样式与其他作品

调整作品后，选择“保存到我的样式”并填写名称。之后在其他作品的“我的样式”菜单中复用，正文和结构
保持原样。设置 → 作品样式可以改收藏名称、移除并撤销，以及主动指定新作品的默认样式。
默认值保存一份样式副本：不会改变已有作品，移除收藏也不会使默认值丢失；需要换默认值时再到设置中选择。
内置默认样式会保留预设名称及参数。若此前设置“柔和”后新作品却显示“极简”，更新后请重新选择并保存一次默认值；已有作品不会自动重写。

未设置个人默认值时，新聊天 Widget 跟随应用主题，其他作品使用极简。选择“应用默认”并保存可恢复这个行为。
已有 Widget 保留原来的独立样式；在作品页选择“跟随应用主题”并保存即可切换。跟随模式使用平台配色和排版，
选择一个独立风格后才可以调整各项样式参数或“保存到我的样式”；跟随主题时会禁用收藏按钮并显示说明。
旧版误存的跟随主题收藏仍保留，可以改名、移除和撤销，但不能复用或设为个人默认；请在作品页选择独立风格后重新收藏。
旧版误存的具名跟随主题默认按“应用默认”生效，已有作品不改写。生成规范与兼容限制见 [Widget 视觉与交互](WIDGETS.md)。

“新建作品”提供知识卡片、导图、对比表和时间线。对比表可改列标题、单元格、增删行列，最多 6 列、80 行；
时间线支持时间/阶段、标题、正文和事件顺序，最多 80 条。删除与文字编辑可撤销，保存后使用同一版本历史。

连接模型后，“用文字调风格”只发送当前样式和修改要求，不发送正文，不修改默认设置或其他作品。
“AI 修改 Widget”会发送当前 Widget 源码、样式和修改要求，预览仍在隔离环境中运行。
两者均先生成预览，检查后应用，再保存修改。无效/未完成输出不会应用，已经改变的草稿不会被旧预览覆盖。
Widget 预览中的交互用于检查，应用到编辑页会从修改后的源码重新运行。

## 思维导图

从“我的作品”新建导图，或在回答、笔记和文件阅读页选择创建导图。每行一个节点，两个空格缩进一级，
也可以输入 Markdown 标题与列表。手动创建和编辑不调用模型；最多 200 个节点、12 层，每个节点 300 字符。

点击节点修改文字；可以增加子节点/同级节点，删除分支后撤销。拖到另一个节点可调整父节点，也可使用
“移动到”菜单。支持折叠、缩放和适应画布，以及双向、单向树和大纲视图。节点颜色、字体、大小、圆角、
间距和连线样式独立保存。编辑完点“保存修改”，重启后可以继续编辑。

桌面版可以用 AI 整理本次选择的文字，或扩展/精简选中的分支；需要连接模型。分支请求仅发送选中子树，
结果先预览，再由用户应用；取消、无效输出或已经过期的预览不会覆盖编辑。应用可以撤销，保存保留版本。
来源中的其他记录不会随请求读取，原笔记/文件不会被改写。AI 归纳与建议需要用户核对。

导出 SVG 保留当前布局、可见节点与风格；Markdown 大纲保留全部节点，包括已经折叠的子节点。
PNG/PDF 也可以导出导图，过大的导图需要拆分或使用 SVG。大纲视图同样支持缩放与独立风格。

## 导出与分享

在聊天 Widget 或作品页选择“导出 / 分享”，检查实际预览后保存 PNG、长页 PDF，或复制图片。
静态导出包含当前按钮结果、输入框内容及 canvas 画面，纵向滚动区域会展开。导出不会改变原组件。
导出会冻结当前主题变量和 SVG 的实际颜色/字体，标准滑块保留轨道、滑块位置与当前值。

PNG 使用 2 倍像素渲染；长页 PDF 使用相同画面的图片页，文字不可直接编辑。复杂 CSS、动画、滤镜
或特殊图形可能与原稿不同，以导出预览为准。超过像素或尺寸限制会提示拆分，不会静默裁去尾部。

图片比例可以选原始 / 长图、1:1、4:3、16:9、3:4 或 9:16。固定比例的输出宽度为 1600 像素，
完整内容缩放进画布；较长的正文或较大的导图建议使用原始比例，避免文字缩得太小。
附加标题、来源和署名分别勾选后才进入画面，署名默认空白，不自动读取个人信息。
未勾选的文字输入框会停用；勾选后可以修改。导出窗口将选项和预览分区，窄窗口自动上下排列。
固定比例在预览框内完整显示，原始长图可以滚动查看；底部的导出按钮始终保留。
这些文字绘制在内容外侧，作品原有标题仍保留。保存 PNG、PDF 和复制图片共用当前预览。

Widget 另有“保存离线交互 HTML”：把文件发给对方，用浏览器打开即可操作按钮、输入或计算。
离线文件从保存的源码重新运行，不包含刚才的计算状态，也不套用图片比例；已勾选的附加文字会保留。
跟随应用的 Widget 在离线文件中使用导出时的配色，不再跟随 Seeker 后续的主题变化。
组件在独立沙箱中运行，不能连接应用或外网，因此依赖远程资源或 Seeker 动作的功能不可用。
重新打开文件会回到初始状态。若要分享已完成的计算结果，请使用 PNG 或 PDF。
目前提供文件分享，尚未提供公网托管链接或协作。

桌面文件写入系统下载目录下的 `Seeker` 文件夹，使用新的文件名，不覆盖已有文件；写完会重读校验。
Web 交给浏览器下载，保存位置由浏览器决定。图片剪贴板不受支持或权限失败时，可以保存 PNG。

## 数据范围

作品存在本机，当前可查看所有工作空间中的作品。完整数据备份包含内容、独立样式、来源和版本记录；
精简导出排除作品集合。应用的“移除作品”不会立即清掉这些数据，便于日后恢复。

作品集合没有全库 AI 查询权限。手动编辑、换风格和导出不联网；Widget 自身在隔离环境运行，不能访问
应用数据或外网。聊天生成作品仍使用用户已连接的模型。保存的是 Widget 原稿，重开时交互从原稿初始化；
需要分享某次计算结果时，请在该画面上直接导出。
