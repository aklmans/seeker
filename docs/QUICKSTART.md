# 快速上手 · QUICKSTART

本文对应 Seeker v0.4.0 的个人 AI 工作空间。公开 [Releases](https://github.com/aklmans/seeker/releases) 提供桌面安装包；在线体验适合了解界面与浏览器能力，文件、钥匙串、完整连接器和任务执行以桌面版为准。

## 先做什么

打开后从首页开始：直接提问，或进入“工具”“资料库”“任务”。首次安装默认以日常功能为主；已有安装保留原来的求职数据、应用状态和模型配置。

没有连接模型时，也可以新建笔记、收藏片段、搜索资料、预览已导入文件的文字、导出 Markdown。普通保存与文件解析在本地完成。

## 连接模型

从首页点击“连接模型”，或打开“数据设置 → 模型配置”。

1. 选择模型服务提供的协议：OpenAI 兼容、Anthropic、Gemini 或本地 Ollama。
2. 填写服务地址和完整模型名称。已有配置会原样显示；切换协议不会自动覆盖地址和模型。
3. 云端服务填写自己的 API Key。已配置时留空可保留原 Key；新 Key 只写入系统钥匙串。
4. 点击“保存并测试连接”。测试仅发送固定短请求，连接成功后返回首页即可使用。

本地 Ollama 需要先运行模型服务并准备可用模型，默认兼容地址为 `http://localhost:11434/v1`。
这个协议不需要、也不会读取或转发已保存的云端 Key。需要鉴权的远端兼容代理请选择 OpenAI 兼容。

嵌入模型和 User-Agent 在高级选项中。日常写作、文件问答与资料整理不需要配置嵌入模型。
连接错误时根据页面提示检查地址、模型名、Key、服务状态或服务商额度；失败保留当前输入。

桌面版仍采用自带模型（BYO）方式；需要时可由熟悉模型服务的人员协助首次配置。当前尚未提供托管订阅或免 Key 桌面服务。

## 五个常用操作

| 想做什么 | 操作 |
| --- | --- |
| 提问和追问 | 在首页输入问题并发送；会新建独立对话。首页最近对话或对话下拉框可找回旧记录，重启后可继续 |
| 翻译、润色、总结、写回复 | 打开“工具”，粘贴文字并选少量选项，查看结果后复制或显式保存笔记 |
| 阅读文件 | 在“资料库 → 文件”导入 TXT、Markdown、文字型 PDF 或 DOCX，先看原文，再总结或提问；引用可跳回对应片段 |
| 保留资料 | 新建笔记或保存回答，按需添加标签、收藏和来源链接；支持搜索、编辑、删除撤销和 Markdown 导出 |
| 整理几份资料 | 在“任务”中创建资料整理任务，选择材料、填写目标、核对快照后开始，完成后预览并导出 MD/DOCX |

“保存笔记”“AI 整理”和“加入知识库”是三个不同动作。保存不会自动调用模型，也不会自动授权未来知识检索。

文件单份最多 10 MB；文字工具输入最多 12,000 字符；文件正文及单次整理所选材料合计最多 30,000 字符。
文件解析不还原复杂排版，不提供图片 OCR 或扫描 PDF 识别，超限会要求拆分。

## 使用任务助手

资料整理助手只处理本次选择的 1–5 份文件或笔记。创建时冻结正文和目标，开始执行后才把这些材料发送给当前模型。
可暂停、继续或取消；退出应用不会后台继续，重启后由用户决定恢复。

报告中的事实、模型归纳和建议分别标记。系统检查引用是否存在、文件是否完整；归纳和建议仍需要自己判断。
导出会在下载目录的 Seeker 文件夹创建新副本，原验证报告不变。详见 [资料整理助手](MATERIAL-ORGANIZER.md)。

## 数据、旧应用和网页演示

- 数据默认保存在本机，云端 AI 请求会发送你本次提交的内容给所选服务商。
- 个人信息保持独立隔离，不参加 AI 处理。新功能不会自动扩大原有 AI 数据授权。
- 求职工作台可在左上角“应用管理”开启或关闭；关闭保留数据和已有任务记录。
- 完整备份保全会话、笔记、文件原始字节与正文、任务快照和记录；任务磁盘产物需单独导出保存。
- 网页演示可用本地笔记和备份正文预览。接通演示代理时可聊天；独立文字生成、文件解析/问答和桌面任务执行只在桌面提供。

遇到问题可按 [反馈模板](FEEDBACK.md) 记录操作、实际结果与预期；不要附上 API Key 或不想分享的个人资料。
需要复查任务边界时，可使用 [固定材料与验收说明](ROUND-1-ACCEPTANCE.md)。
