# 第二轮 · 可编辑作品与个人工作空间

状态：用户已批准的五个功能增量及追加弹窗调整均已实现，自动化检查与本机桌面贯通验收通过，进度见
[ROUND-2-PROGRESS.md](ROUND-2-PROGRESS.md)，验收范围见 [ROUND-2-ACCEPTANCE.md](ROUND-2-ACCEPTANCE.md)。
此文件保留整轮范围；本轮未打包、推送或发布，真实模型质量和 Windows 真机留待后续验证。

目标：普通用户从回答、笔记或资料生成作品，编辑内容、采用个人样式、导出分享，重启后继续使用；同时能直接设置自己的工作空间和管理数据，求职工作台由用户主动开启。

## 增量与验收

1. **工作空间与设置**：把现有项目提升为直接可见的工作空间管理入口，支持创建、改名、指令、切换和归档恢复；提供启动页面与首页展示偏好。工作空间隔离会话，现有资料和任务仍为设备共享，界面明确范围。移除按旧安装或存有求职数据自动开启应用的逻辑；旧版自动产生的求职开启记录迁移为关闭，数据原样保留，新版明确的用户选择持久保留。设置使用通用定位，数据页区分工作空间会话、共享资料、任务与应用数据，并说明完整备份范围。修正此次触达的假外观设置。
2. **作品基础与 Widget**：持久保存作品内容、来源、类型、独立样式与修改记录，支持重命名、复制、重新编辑和撤销；聊天生成 Widget 自动保存并能从历史重开。保留现有 iframe 沙箱/CSP，不为编辑和导出开放同源权限。支持高清 PNG、复制图片和 PDF，导出预览与长内容完整呈现。
3. **思维导图**：回答、笔记、选中资料或手动大纲创建；节点增删改、层级拖动、折叠、缩放和适配；双向导图、单向树、大纲视图；选中分支 AI 扩展/精简；SVG 和 Markdown 大纲导出。AI 只读本次选择的材料，手动操作不调用模型。
4. **风格与常用作品**：六个风格起点（极简、商务、手绘、柔和、杂志、深色），支持配色、背景、字体大小、间距、圆角，以及导图节点/连线；保存“我的样式”，用户在设置中主动选择默认样式；自然语言修改当前作品风格，保留内容和可恢复版本。增加知识卡片、对比表、时间线，复用保存、样式和导出。自由 Widget 支持 AI 修改及版本恢复，不谎称任意 HTML 都可逐元素可靠编辑。
5. **分享与整轮验收**：常用横竖比例、标题、来源和署名选择；交互作品静态导出呈现当前状态，另提供保留交互的受限离线查看方式。贯通双语、备份恢复、无模型编辑、失败处理和实际桌面导出；全量检查及用户说明。

公网分享托管链接、多人协作、XMind 文件兼容和参考图提取样式仍在后续范围，不引入新的收费服务。

## 数据与架构约束

- 应用界面延续 Seeker 设计语言；用户作品使用独立、可自定义的输出样式。
- 内容、结构、样式分别保存。手动换样式、布局、导出不调用模型，也不重新生成正文。
- 新数据同步核对 Runtime 类型、SQLite 表映射、Web IndexedDB、完整备份、脱敏导出和 AI 静态白名单。作品与样式默认不开放全库 AI 查询。
- 工作空间指令、启用应用和默认样式仅由可信设置界面修改，AI 不能修改自己的运行配置。
- 关闭应用和归档工作空间不删除数据；删除/覆盖沿用可靠 guardrail/undo，写失败不报告成功。
