# 工作空间与数据设置

在侧栏打开「工作空间」，或从首页右侧的空间按钮进入。可以创建学习、工作、生活等空间，修改名称和助手指令，或归档暂时不用的空间。归档保留对话，随时可还原。

每个空间拥有自己的对话列表和聊天指令。资料库、文件、任务、应用开关和模型连接在本机共享；切换空间不会搬动或复制这些记录。写作、文件问答和固定任务仍使用各自选中的输入，不自动采用聊天空间指令。

「本机工作台偏好」可以修改默认空间名称、启动页面，以及是否在首页显示最近资料和最近任务。点击「保存偏好」后生效，启动页面在下次打开时使用。关闭某应用后，它的启动页不可用时会回到首页。

求职工作台默认关闭，在工作空间页或应用管理中可主动开启。旧版启用记录无法区分自动开启与用户选择，因此升级后旧记录恢复为按需关闭；再次手动开启后持续保存。关闭应用不删除岗位、简历或历史任务。

「设置」包含真实外观设置、模型配置、可选个人信息、数据管理和工作空间入口。个人信息默认空白，只在本机的隔离通道保存，AI 不读取；开启求职后才显示求职字段。

数据页显示当前工作空间消息和本机共享数据的数量。完整 JSON 备份覆盖全部空间和已关闭应用的数据，并包含个人信息、导入资料原文件与便携偏好；不包含系统钥匙串密钥。已生成的外部报告文件需自行另外保留。精简导出仍可能包含对话、笔记或业务正文，分享前需要检查。

历史管理可切换查看当前或全部空间。清除按钮明确针对全部空间的消息与会话，先保存可导入的完整备份，再一次性删除；备份或删除失败不会显示成功。需要恢复时，在设置中导入之前的 JSON 备份。
