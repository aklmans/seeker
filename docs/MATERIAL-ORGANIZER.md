# 资料整理助手

资料整理助手把几份文件或笔记整理成可检查的报告，适合比较产品说明、归纳会议材料和列出待确认问题。
在桌面版的“任务”中使用。资料库无需配置模型；执行整理任务需要先连接模型。

## 操作

1. 在资料库导入 TXT、Markdown、文字型 PDF 或 DOCX，或保存普通笔记。
2. 打开“任务”→“新建任务”→“资料整理助手”。
3. 选择 1–5 份资料，填写具体目标，并选择中文或英文报告。
4. 点击“创建并检查”，核对保存的资料快照、权限与交付物，再点击“开始执行”。
5. 完成后预览 Markdown，按 `[s1/f1]` 等来源编号核对任务中的原文快照。需要编辑可另存笔记。
6. 点击“导出副本”获得 Markdown 或 DOCX。副本保存到下载目录的 Seeker 文件夹；原报告保持不变。

单文件最多 10 MB；本任务所选正文合计最多 30,000 字符。超限会要求减少或拆分资料，
不会默默截断。扫描 PDF、图片 OCR、复杂排版还原、网页研究不在首轮范围内。

## 数据与报告

创建任务会把选定资料的正文和目标保存为本次快照。后续修改或删除原资料，不会改变这份任务。
要用更新后的资料或新的整理目标，请重新创建任务。模型只在开始运行后收到明确选择的资料。
使用云端服务时，这些正文会发送到当前服务商；本流程不会读取其他笔记、聊天、知识库或个人隐私字段。

报告包括概览、分材料要点、综合整理、资料缺口和来源。资料事实、模型归纳和待确认建议有不同标记。
系统检查引用是否逐字存在于所选原文，并检查报告文件是否完整写入。归纳是否忠实、建议是否合理，仍需使用者判断。

## 暂停、取消和异常

- 暂停在安全检查点生效；继续时保留已完成的提取，当前未完成模型步骤可能重新调用。
- 取消会结束当前运行，后续步骤不再执行。需要重新整理时创建新任务。
- 退出应用不会在后台继续。重启后中断的任务由你决定是否继续。
- 写入异常时不会显示“已完成”；继续前先核对已有文件，必要时清理这次运行的不完整文件后重建。
- 报告被外部修改、移动或删除后，打开/导出时会拒绝把它当作已验证产物。

网页演示可以展示完整备份中的任务和快照，不能执行桌面任务或打开桌面路径。
完整备份保全任务快照和验证记录，磁盘产物本身不会因此成为网页端可访问文件。

首轮内测仍为自带模型服务；没有托管订阅或免 Key 桌面服务。协议链路和文件验证使用确定性测试，
真实模型质量需在可用服务上另行抽查。
